HOW TO ADD PHOTOS — NO CODE EDITING REQUIRED
==============================================

To give any place a real photo, just save an image file into THIS folder
(client/public/images/) using the EXACT filename listed below for that
place. That's it — no JSON, no code, nothing else to edit. Refresh your
browser (Ctrl+Shift+R) after adding a file and the photo appears.

Accepted file types: .jpg, .jpeg, .png, .webp — just match the name before
the dot; the extension can be any of those four.

If a file isn't there yet, that place just shows a neutral placeholder
photo — nothing breaks.

HOW TO SAVE A PHOTO FROM GOOGLE MAPS
--------------------------------------------------
1. Search the place name on Google Maps
2. Click its listing, then click its Photos
3. Right-click a photo -> "Save image as..."
4. In the filename box, type the exact name from the list above
   (e.g. le-paquebot-douala) and save it into THIS folder
5. Refresh your browser (Ctrl+Shift+R)

Done. No code, no JSON editing.
